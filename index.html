热力学第一定律公式助手

物理化学 · 第一定律 ｜ 35 条公式速查 · 11 过程速判 · 22 记忆卡 · 17 易错点

选择过程类型（理想气体、W′ = 0）：

最容易丢分的 17 个点

  • 符号约定：ΔU = Q + W 中 W 是「环境对系统做功」；若教材用「系统对外做功为正」，则写成 ΔU = Q − W。换教材先确认。
  • Qp = ΔH 有条件：必须封闭系统、等压、且不做非体积功（W′ = 0，W′ 为非体积功）。有电功、表面功时不成立。
  • QV = ΔU 有条件：等容且 W′ = 0，缺一不可。
  • 理想气体的 ΔU、ΔH 只看 ΔT：不管过程可逆与否、是否等温等压，直接用 nCV,mΔT、nCp,mΔT（热容视为常数）。
  • 绝热 ≠ 可逆：绝热不可逆过程不能用 pVγ = 常数这一套方程，只能用 Q = 0 与 ΔU = W 联立求 T₂。
  • 绝热不可逆的功：若外压恒定，W = −p外(V₂−V₁)，再令它等于 nCV,m(T₂−T₁) 解出 T₂。
  • Cp,m − CV,m = R 只对理想气体成立，凝聚相不适用。
  • 等温可逆功要用系统压力积分：W = −∫p dV，p = nRT/V，不是用外压。
  • 恒外压功：W = −p外ΔV，与系统内部压力无关；向真空膨胀 W = 0。
  • 焓变与热力学能变的关系：ΔH = ΔU + Δ(pV)。理想气体 Δ(pV) = Δn(g)RT；凝聚相 Δ(pV) ≈ 0，故 ΔH ≈ ΔU。
  • 基尔霍夫定律：ΔCp = ΣνBCp,m(B)，产物为正、反应物为负。
  • 燃烧焓方向：ΔrHm° = −ΣνBΔcHm°(B)，别漏负号。
  • 节流膨胀是等焓不是等温：理想气体 μJ-T = 0 才是等温；真实气体一般会变温。
  • 等温等容反应 W = 0，但 ΔrHm ≠ ΔrUm：必须用 ΔrHm = ΔrUm + Δr(pV) 换算，理想气体时 Δr(pV) = RTΔrn(g)。
  • 等温等压反应 ΔrUm = ΔrHm − p外ΔV：算热力学能变时别忘了扣掉体积功，气体反应时 ΔV ≈ Δn(g)RT/p。
  • 不可逆相变的 Qp ≠ ΔH相变：ΔH相变 只在相平衡温度下有意义；不可逆相变的 ΔH 需另设可逆途径计算，ΔU 用 ΔU = Q + W 求。
  • 可逆相变必须在相平衡温度下发生（如正常沸点、正常熔点、平衡蒸气压下），否则就是不可逆相变。
